# 🏏 Cricket Analytics Dashboard

## 📌 Project Overview

This project analyzes T20 cricket data to identify top-performing players, suggest the best playing XI, and recommend a captain using data-driven insights.

## ⚙️ Tech Stack

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* SQL (for data modeling)

## 📊 Features

* Player performance analysis
* Consistency distribution
* Best XI selection
* Captain recommendation

## 🚀 How to Run

1. Open the notebook in Google Colab
2. Upload dataset files
3. Run all cells

## 📈 Outcome

Built an end-to-end analytics workflow including data cleaning, transformation, modeling, and visualization.
